# Macro Security

Prototipo de centro de mando para seguridad ciudadana: reportes por WhatsApp, patrullas, pronóstico por turnos y análisis por zona, sobre el mapa real de OpenStreetMap.

- Abre `index.html` (o la página publicada) en Chrome o Edge.
- Datos simulados. En Configuración → Lugar se puede elegir cualquier municipio de México.
- Los datos se guardan solo en el navegador de quien lo abre.
